# Board LEDs

## Status colours

| Colour            | Meaning                            |
| :---------------- | :--------------------------------- |
| Amber             | Booting...                         |
| White (breathing) | Ready / Idle                       |
| Green             | TX (host → controller)             |
| Blue              | RX (controller → host)             |
| Cyan              | TX and RX                          |
| Red               | Packet dropped (host not draining) |
