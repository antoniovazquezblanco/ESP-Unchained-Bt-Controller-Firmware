# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** and do not open a public issue for them.

Use GitHub's private vulnerability reporting for this repository via the **"Report a vulnerability"** button on the *Security* tab, or directly at:
<https://github.com/antoniovazquezblanco/ESP-Unchained-Bt-Controller-Firmware/security/advisories/new>

This opens a private advisory visible only to the maintainers.

Please include:
- A description of the issue and its impact
- The affected component (firmware, CI configuration, ...)
- Steps to reproduce or a proof of concept
- Any suggested fix, if you have one

We will acknowledge the report, investigate, and coordinate a fix and its disclosure with you.
